# Accepted Responsibility（責任の引き受け）

仕事を完遂する責任は、必要な情報と裁量を知った人が自分で引き受ける。名前を担当欄に入れても、その人が優先順位を変えられず、必要な判断もできなければ、仕事は途中で止まる。何を達成すれば完了か、本人が決められること、ほかの人に頼むことを引き受ける前に話す。

## データ移行の当日判断を任せる

移行を引き受けたい人と、準備から切り戻しまでをたどる。実行結果を読む権限はあっても、差異が出たときに停止を決める権限がなければ、当日に誰かを探すことになる。「件数に差があれば担当者が次のバッチを止める」「顧客への連絡は窓口が担う」と当事者間で合意し、負担が大きければ担当範囲を分け直す。リハーサルで差異を一件起こし、引き受けた人が情報を読んで停止でき、窓口まで連絡が届くかを確かめる。
