# Opportunity（機会）

繰り返す不具合や問い合わせには、利用者が本当は何をしたかったのか、作り手が何を見落としたのかを知る機会がある。まず困っている人が作業を再開できるようにする。そのうえで、起きた問題からどんな新しい能力を得られるかを考え、当事者と次の一歩を選ぶ。

## 入力エラーを使って受付を改善する

申請のたびに添付ファイルが受理されず、窓口が一件ずつ変換しているとする。担当者に実際の申請を見せてもらうと、利用者は形式の制約を送信後に初めて知り、再送時には記入済みの項目まで失っていた。まず受付を済ませたうえで、ファイル選択時に利用できる形式を示し、選び直しても記入内容を保つ案を試す。問い合わせ数に加え、いったんエラーになった利用者が自力で申請を完了できたかを確かめると、諦めて離脱した人を成功に数えずに済む。
