# Baby Steps（ベイビーステップ）

一歩進むたびに結果が分かり、想定が外れても直前の動く状態へ戻れる大きさに変更を切る。切り方は変更行数より、試して答えられる問いで決める。一歩終えても何が正しかったのか分からないなら、先に一つの条件だけを観察できるようにする。

## 日付の扱いを呼び出し元ごとに移す

日付計算を共通化するとき、すべての呼び出し元を一度に置き換えると、不一致が出たときに原因を絞りにくい。まず予約期限を計算する一か所で、月末の入力と期待する期限を既存の呼び出し口から確かめる。その一か所を新しい計算に切り替え、同じ例を再実行する。結果が変われば、直前の変更だけを調べるか戻せる。通ったら、次に休日を考慮する呼び出し元を選び、その違いを示す例を先に用意する。残る箇所が別々に移せることも、最初の一歩で確かめたい結果の一つである。
