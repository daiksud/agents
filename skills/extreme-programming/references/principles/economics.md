# Economics（経済性）

同じ成果でも、いつ使い始められるかで価値は変わる。今日の実装費に加え、利用者が待つあいだの負担、保守費、後で選択を変える費用を比べる。判断を延ばせば新しい情報を得られる場合は、何がいつ分かるのかを確かめる。待つ間の損失が大きければ、当面の需要を満たす小さな実装を先に届ける理由がある。

## 自動化の順番を決める

月末に限って使う集計のため、経理が毎回2日かけて転記しているとする。製品全体の帳票基盤を今作る案と、今月必要な表を1枚出す案について、いつから作業を省けるか、表の形式が変わったらどれだけ手直しが要るかを見積もる。まず1枚で足りるなら、それを月末に使ってもらう。実際に省けた時間と残った手作業を聞けば、次に自動化する帳票に費用をかける価値を判断できる。
