## XP Values

個別のValueをArchitecture、Delivery、DDD等の補助lensとして使うときに読む。XP全taxonomyを読む必要はない。

| Value | 診断上の意味・観測例 |
| --- | --- |
| Communication | 目的・ルール・具体例・未回答事項が必要な人へ伝わり、異なる理解を実装・運用前に確かめられるかを見る |
| Simplicity | 現在確認されている要求を満たす最小で理解しやすい選択を取り、予測だけの複雑さを先取りしていないかを見る |
| Feedback | test・integration・利用者・production等から早く結果を得て、次の小さい判断へ反映できるかを見る |
| Courage | 不確実性・欠陥・不要な複雑さを隠さず、証拠と既存契約を根拠に必要な変更を選べるかを見る |
| Respect | 利用者の判断権限、関係者の知識・時間、持続可能な働き方を尊重し、一方的な負担へ依存していないかを見る |

Value名の有無や宣言だけで実践済みと判定しない。現在のproblemに関係するValueだけを使う。
